# Markdown 注音自用卡片设计

## 状态

当前设计，2026-07-18 实施。

## 目标

在 Gleamory 中记录正在使用的 Markdown Furigana Local 插件，说明本地增强能力和维护来源，同时避免形成公开分发或官方插件的误解。

## 页面结构

- 首页项目名称为“Markdown 注音”，归入“笺墨相助”，状态为“开发中”。
- `#/markdown-furigana` 复用插件详情页骨架，展示功能、真实 Obsidian 截图、使用语法和来源链接。
- 标题后固定显示“个人自用维护版本”说明；不渲染下载按钮、安装流程或个人仓库入口。
- 来源分别指向 Steven Kraft 上游仓库和 phoenix-meadowlark 的 PR #34，并在页面注明原作者与本地维护关系。

## 验收

- 首页卡片可达详情页，桌面和窄屏均无裁切。
- 页面能看到自用说明、两张真实截图、五条使用示例和两个来源链接。
- 页面中不存在包含“下载”的操作链接。
