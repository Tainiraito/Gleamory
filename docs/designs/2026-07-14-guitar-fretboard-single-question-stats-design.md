# 吉他指板单题计时与准确率精简设计

**日期：** 2026-07-14  
**状态：** 已确认  
**范围：** 今日练习的出题生命周期、单题计时、单题准确率和本地存储精简

## 1. 目标

今日练习不再使用“每日记录”或“练习轮次”概念。页面只呈现当前题目的实时用时和作答后的准确率，不展示或保存跨题、跨日历史。

本次调整同时删除每日指标、按题型详情、日期弹窗、365 天热力图以及对应的每日聚合和逐题持久化逻辑，避免界面已隐藏但后台仍持续记录。

## 2. 单题生命周期

今日练习使用以下状态：

1. **未生成：** 页面首次打开时没有题目；指板不可作答；题目区域显示空状态和“生成题目”按钮。
2. **作答中：** 点击“生成题目”后按当前出题配置生成一道题，并以生成时刻为起点开始计时。
3. **已完成：** 提交多选答案或点击单选答案后结束计时，冻结当前题用时并计算准确率。
4. **下一题：** 点击“下一题”立即生成新题，用时和准确率同时重置。
5. **跳过：** 点击“跳过此题”不产生准确率，直接生成新题并重新计时。

更改出题配置时终止当前题并回到“未生成”，防止题干、可选范围和配置不一致。离开“今日练习”Tab 不暂停计时；返回后按实际经过时间继续显示。

“重置”只清空当前题已选择的答案，不改变题目，也不重新开始计时。

## 3. 用时

- 未生成题目时显示 `用时 --`。
- 作答中每 100 毫秒刷新一次展示值，格式为秒并保留一位小数，例如 `用时 3.2 秒`。
- 作答完成后使用 `QuizAnswer.responseMs` 冻结结果，后续渲染不得继续增长。
- 高频计时状态封装在题目统计组件内部，避免整个指板页面每 100 毫秒重渲染。

## 4. 准确率

未完成作答时显示 `准确率 --`。作答完成后：

- 认音单选题：答案正确为 `100%`，错误为 `0%`。
- 指板多选题：使用标准答案集合与用户选择集合的交并比。

公式：

```text
准确率 = 正确选中数 / (标准答案数 + 错选数)
```

等价于：

```text
|标准答案 ∩ 用户选择| / |标准答案 ∪ 用户选择|
```

结果限制在 `0-1`，界面四舍五入为整数百分比。示例：标准答案 5 个，选对 4 个且无错选为 `80%`；选对 4 个并错选 1 个为 `67%`；全部选对但多选 1 个为 `83%`。

准确率作为纯函数放在 `src/lib/guitarFretboard/quiz.ts`，不依赖 React 状态。

## 5. 界面调整

题目区域继续位于指板和 Tab 之间，便于对照：

- 未生成时显示简短空状态和“生成题目”主按钮。
- 生成后显示题干、可选范围、`用时`、`准确率`、答案控件和当前反馈。
- 今日练习配置区域保留出题方式、随机范围、自选题型和练习范围，不再显示统计卡片或热力图。
- 不提供统计项点击弹窗，不新增记录入口。

## 6. 数据与兼容

`StoredFretboardState` 只保存 `settings`。删除：

- `sessions`
- `dailyRecords`
- `skillStates`
- `PracticeSession`
- `DailyPracticeRecord`
- `PracticeDay`
- 每日聚合和日期汇总函数

加载旧版存储时只读取并归一化 `settings`，忽略旧历史字段。下一次保存设置时以精简结构覆盖旧值，从而不再保留历史练习数据。读取损坏或不可用的本地存储时仍回退默认设置。

删除不再使用的 `PracticeStats`、`PracticeHeatmap`、`PracticeDetailDialog` 及其测试和专用样式。

## 7. 边界规则

- 未生成题目时，点击指板不能选中练习答案。
- 单选题点击答案后立即验证并冻结计时。
- 多选题点击“提交答案”后验证并冻结计时。
- 已完成题目不能再次提交或改变答案。
- 题目答案为空时提交，准确率为 `0%`。
- 不新增依赖，不引入后台、数据库或账号体系。

## 8. 验收标准

1. 首次进入页面没有默认题目，存在“生成题目”按钮。
2. 生成题目后计时从零开始增长，答题完成后停止。
3. 重置当前选择不会重启计时。
4. 单选题准确率只有 `0%` 或 `100%`。
5. 多选题按交并比展示部分准确率，漏选和错选均会扣分。
6. 下一题和跳过都会生成新题并重新计时。
7. 页面不存在每日指标、统计详情弹窗或 365 天热力图。
8. 本地存储不再写入逐题、每日或技能历史，只保存设置。
9. 相关单元测试、页面测试、全量测试、Lint 和生产构建通过。
