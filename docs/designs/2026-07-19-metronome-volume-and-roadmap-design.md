# 节拍器音量控制与优化路线图设计

## 目标与范围

本次将节拍器更新到 `v1.2.0`，只交付播放音量控制。Tap Tempo、逐拍重音、预设和练习模式等调研结论保留为后续路线图，不与本次改动一起发布。

## 音量交互

- 播放区顺序为“停止、播放/暂停、音量、计时与轮次”。音量按钮显示静音、低音量或正常音量图标。
- 点击音量按钮，在其上方打开滑杆面板。滑杆范围为 0–100%，步进为 1%，默认值为 80%，0% 即静音。
- 音量按钮只打开或关闭面板，不承担一键静音，避免用户误触后找不到原音量。
- 面板支持滑杆键盘操作、外部点击关闭与 Escape 关闭。Escape 关闭后焦点返回音量按钮。
- 窄屏把计时和轮次换到第二行，停止、播放和音量仍在同一组内。

## 音频与存储

- AudioContext 首次由用户播放或试听拍点时创建，同时建立唯一的主 GainNode。
- 每个拍点自身只表达主拍 `1`、细分拍 `0.5` 的相对强度，最终统一连接主 GainNode。
- 播放中调整主增益时使用短时间平滑过渡，避免爆音，不重新创建 AudioContext。
- 使用 `gleamory:metronome:volume` 保存归一化后的 `0–1` 数值。读取时验证有限数字并限制范围；异常时回退到 `0.8`。

## 竞品调研与后续优先级

调研参考 [Metronome Beats](https://stonekick.com/metronome.html)、[Soundbrenner](https://www.soundbrenner.com/pages/manual-the-metronome-app)、[Pro Metronome](https://eumlab.com/pro-metronome/) 和 [Tempo](https://frozenape.com/tempo-metronome.html)。Gleamory 已具备多小节、独立细分、音色编排和渐进变速，后续优先补足练习闭环。

| 优先级 | 能力 | 后续方向 |
| --- | --- | --- |
| P1 | Tap Tempo | 根据最近多次敲击间隔计算 BPM，停顿后重新采样。 |
| P1 | 逐拍重音与静音 | 在现有音色外增加重音等级和静音状态，支持纯视觉跟拍。 |
| P1 | 本地预设 | 保存常用 BPM、拍型、细分、音色和多小节结构，暂不做云同步。 |
| P1 | 拍点编辑可发现性 | 为长按或右键编辑增加显式提示，统一 Pointer、触摸和键盘操作。 |
| P2 | 预备拍、倒计时和自动停止 | 支持按时间或小节数结束练习。 |
| P2 | 静音小节训练 | 配置“响 N 小节、静 M 小节”，复用现有轮次计数。 |
| P2 | 完整拍号与 Swing | 明确拍号分母、复合拍和 BPM 语义。 |
| P3 | 舞台与高级模式 | 评估全屏视觉、振动、歌单和多节奏。 |

云同步、社交和打卡不符合当前纯前端个人工具定位，暂缓。另将“停止后清理已排队的拍点高亮回调”和“校验变速模式起止 BPM”登记为独立质量任务，不在本次音量功能中顺带修改。

## 验收

- 主拍、细分拍和拍点试听都受同一音量控制，播放中调整立即生效。
- 刷新页面后恢复上次音量；损坏存储或禁用存储时使用默认 80%。
- 桌面与 320px 窄屏均无控制裁切，音量面板不引发布局跳动。
- 鼠标、触摸与键盘都可打开、调节和关闭音量面板。
