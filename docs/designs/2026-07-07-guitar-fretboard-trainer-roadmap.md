# 指板音训练后续扩展留档

日期：2026-07-07

状态更新：2026-07-14。五类题型和单题计时/准确率已经进入当前版本；每日练习热力图、题型历史明细和跨题持久化已撤回。本文其余条目仍是延期候选，不属于当前版本验收范围。

本页记录「指板音训练」首版未纳入但后续值得继续做的内容，避免只停留在聊天记录中。

## 首版边界

- 已纳入：6 弦 0-24 品指板、常用调弦、点击采样发声、五类题型、单题计时与准确率、本地设置。
- 暂不纳入：账号、后端、云同步、麦克风识别、多乐器、多弦数、完整曲谱学习。

## 采样音色扩展

- 首版采样来源：University of Iowa Musical Instrument Samples - Guitar。
- 首版运行时策略：使用 `mf`、mono、开放弦 E2/A2/D3/G3/B3/E4 六个采样点，通过 Web Audio `playbackRate` 覆盖其他品位。
- 后续可扩展为每根弦多采样点，例如每 3-4 个半音一个采样，减少高把位音色变形。
- 后续可增加力度层：`pp`、`mf`、`ff`，根据练习状态或设置选择音色。
- 若要支持 Safari 兼容性，需要补 `.m4a` 或 `.wav` fallback，并在 manifest 中声明格式优先级。

## 学习系统扩展

- 当前非目标：默认保存逐题记录、每日聚合、365 天热力图或技能状态。
- 热力图：按弦、品、音名显示熟练度。
- IndexedDB：当练习记录超过 localStorage 舒适容量时迁移。
- 导入导出：JSON 包含设置、练习记录、技能状态、自定义调弦。
- 复习调度：从当前简化弱项推荐升级为更接近 FSRS 的稳定度模型。
- 今日练习：加入到期复习、薄弱强化、新内容三类权重。

以上学习系统条目仅作为未来重新立项时的候选，不得视为当前承诺；若恢复记录能力，应先提供明确开关、数据范围和清除机制。

## 题型扩展

- 单弦专项：限定一根弦训练自然音或全部音。
- 把位专项：限定 5-8、7-10 等常用把位。
- 已完成：八度题、音程题和大调调内音训练的基础版本。
- 后续扩展：更多音程、自然小调、大调五声音阶和小调五声音阶题型。
- 限时速度题：固定时长内尽可能正确作答。

## UI 与体验扩展

- 已完成：四套固定指板外观预设、十二平均律递减品距、六弦独立粗细、缠弦/钢弦质感、琴枕与真实品位标记。
- 移动端 0-12 / 12-24 快速切换，减少横向滚动负担。
- 更细的指板缩放控制。
- 练习结束页展示最容易错的音名、弦、品格范围。
- 更完整的设置页：音量、音长、显示偏好、清空数据确认。
- 后续外观扩展：自定义材质编辑器、原声/电吉他/古典吉他弦组、不同弦长与琴型、多弦琴和高精度位图木纹。

## 技术注意事项

- 保持纯前端和 GitHub Pages 可部署。
- 业务逻辑继续放在 `src/lib/guitarFretboard/`，页面组件只处理状态和展示。
- 新题型必须先补单元测试，再接 UI。
- 采样来源和授权说明必须随 manifest 或文档保存。
