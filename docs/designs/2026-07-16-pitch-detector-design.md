# 音高检测 v0.1.0 设计

> 状态：当前实现与验收入口
> 日期：2026-07-16

## 目标

在不上传用户音频的前提下，为 Gleamory 提供一个可直接使用的音高检测工具：既能监听实时输入，也能分析上传文件，并允许把音轨分离结果继续送入检测。

## 用户流程

### 实时检测

1. 用户选择麦克风或电脑音频。
2. 浏览器在用户点击“开始”后申请权限并创建 AudioContext。
3. 页面按固定步长采样，显示音名、频率、音分偏差、置信度和最近 180 秒曲线。
4. 麦克风默认启用环境降噪；页面对短暂丢帧进行稳定处理，用户可在开始前关闭降噪。
5. 用户可以暂停、继续、清空；暂停后生成可回放录音，既可点击播放按钮，也可点击曲线定位播放。
6. 用户可点击纵轴音名播放本地钢琴参照音，对照自己的发声。

### 上传分析

1. 用户选择浏览器可解码的本地音频。
2. 页面校验 100 MB 文件大小和 10 分钟时长。
3. 音频在浏览器中解码为单声道样本，分帧检测并平滑音高轨迹。
4. 用户可以缩放、拖动、点击曲线，并同步定位本地音频播放。

### 分轨结果接续

1. 音轨分离完成后，用户点击某个结果卡的“检测音高”。
2. 分轨数据编码为临时 WAV Blob，通过内存传递 ID 导航到 `#/pitch-detector`。
3. 音高页面消费该临时记录后立即删除传递项，并进入上传分析流程。

## 架构边界

```text
PitchDetectorPage
  -> pitch.ts：音高检测、分帧与平滑
  -> pitchView.ts：视口、缩放、平移和坐标换算
  -> pitchTransfer.ts：同一 SPA 会话内的一次性 Blob 交接
  -> decode.ts / music.ts：浏览器解码与音名换算
```

- 页面负责权限、媒体生命周期和交互状态。
- 算法、曲线坐标和临时传递保持为可独立测试的纯逻辑模块。
- 不增加后端、云存储或用户音频上传。
- 非首页页面继续使用 `React.lazy` 分包。

## 状态与错误

- 实时状态：`idle`、`running`、`paused`。
- 上传状态：`idle`、`analyzing`、`done`、`error`。
- 权限拒绝、无音轨、文件过大、时长超限、解码失败和临时传递失效都显示可操作提示。
- 页面卸载时停止媒体轨道、取消动画帧、断开节点、关闭实时 AudioContext 并释放对象 URL。

## 视觉与信息层级

2026-07-16 的界面重设计采用“编辑式调音工作台”，不再沿用大标题、漂浮模式切换、四个同权指标卡和独立侧栏卡片的组合。

- 参考 Nail the Pitch 的钢琴卷帘式连续轨迹，将曲线作为主工作区，而不是把它放在指标卡之后。
- 参考成熟半音调音器的单一读数焦点，优先显示大音名、频率和横向音分偏差标尺；不采用与 Gleamory 风格冲突的深色霓虹圆形仪表盘。
- 参考专业音频工具的时间轴操作，把播放头、缩放、显示全部和点击回放收进曲线工具栏。
- 全页只保留一个象牙色工作台框体：左侧为输入和回放控制，右侧为当前读数与轨迹；避免卡片套卡片。
- 保持 `--bg-page` 暖纸背景、墨黑正文和琥珀强调色，圆角收敛为 8–12 px，控件使用统一的 Lucide 细线图标。
- 桌面优先展示完整工作台；窄屏按“模式 → 输入/回放 → 当前读数 → 曲线”顺序自然堆叠，不隐藏关键操作。
- 工作台顶栏只保留单行本机处理提示，曲线区直接从当前读数开始，避免重复标题和操作说明占用首屏。
- 曲线 SVG 的展示比例与内部坐标系一致，宽度跟随结果区、高度自然计算，避免固定高度缩放产生左右空白。
- 模式 Tab 与输入来源使用琥珀浅底、强调边框和状态圆点标示当前选择；开始检测保持深色主操作，避免“选中项”和“可执行动作”视觉同权。
- 输入来源选中态已能表达当前来源，因此标题下不再重复显示“麦克风输入 / 屏幕或标签页音频”。
- 当前音名不使用省略号截断，升降号与八度必须完整显示。
- 纵轴使用对数频率映射，使相同音程具有相同距离；刻度音名同时作为可聚焦、可点击的钢琴参照音按钮。
- 错误提示由侧栏内边距容器约束，长消息允许任意断行；共享滑块使用可辨识的中性底轨、琥珀进度和带描边滑块，保证音量与播放进度在暖色背景上清晰可见。

视觉层级固定为：

```text
紧凑页头
  -> 实时检测 / 上传分析
  -> 输入与回放控制 | 大音名 + 音分标尺
                   | 连续音高轨迹与时间轴工具
```

## 验收

- 首页卡片可进入 `#/pitch-detector`，生产构建生成独立页面 chunk。
- 实时与上传两个 Tab 可切换，权限错误后仍可重试。
- 干净正弦波、静音、严格置信度阈值和短音频边界有算法测试。
- 实时短断点稳定、对数纵轴、录音播放状态和纵轴参照音有自动测试。
- 项目元数据、时间线、README、CHANGELOG 和需求文档保持一致。
- 通过全量测试、ESLint、生产构建和桌面/移动浏览器冒烟验证。
