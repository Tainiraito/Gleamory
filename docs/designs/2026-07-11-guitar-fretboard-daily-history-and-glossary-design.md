# 吉他指板每日记录与术语交互设计

**日期：** 2026-07-11  
**状态：** 已确认  
**范围：** 指板点击显示、术语解释、今日统计、最近 365 天练习记录

## 1. 目标

本轮解决四类问题：

1. 指板地图和设置试听在定时淡出后仍残留选中圆点。
2. 音阶、和弦类配置缺少适合初学者的术语解释。
3. 今日练习统计混入历史记录，不能按本地自然日重置和查看题型明细。
4. 缺少类似 GitHub contribution graph 的长期练习反馈。

继续保持纯前端、本地存储和现有单页结构，不恢复独立“记录”Tab，不增加生产依赖。

## 2. 点击显示规则

“点击音名显示”只控制非答题场景：

| 场景 | 持续显示 | 定时淡出 | 不显示点击音名 |
|---|---|---|---|
| 指板地图 | 圆点和音名保留，右键取消 | 到期后圆点和音名一起消失并取消选中 | 点击只播放，不留下圆点或音名 |
| 设置试听 | 与指板地图相同 | 与指板地图相同 | 与指板地图相同 |
| 今日练习 | 不受该设置影响 | 不淡出任何答题内容 | 不隐藏任何答题内容 |

今日练习中的答案选择只能通过右键、重置、跳过、提交或切题清除，避免多选题因定时器无法完成。

## 3. 术语系统扩展

### 3.1 新增词条

在现有 16 个词条基础上增加：

- 音阶
- 和弦
- 自然小调
- 小五声音阶
- 大三和弦
- 小三和弦
- 属七和弦

“大调音阶”继续作为“大调”的别名。地图“显示内容”按钮文字接入 `GlossaryText`，使上述术语可直接触发解释。

### 3.2 无限层嵌套与循环保护

移除固定三层上限。相关词条可以继续展开，只保留访问路径保护：当目标词条已经出现在当前路径中时，将该入口渲染为普通文本，防止 A -> B -> A 无限递归。关闭父浮层时，其后代浮层同步卸载。

### 3.3 延迟悬停与圆环进度

鼠标进入术语后启动 500ms 等待：

1. 术语右上方显示 16px 圆形进度环。
2. 圆环在 500ms 内从 0% 连续填充到 100%。
3. 鼠标提前移出时取消计时并移除圆环，不打开浮层。
4. 达到 500ms 后打开解释浮层并隐藏进度环。
5. 从术语移动到浮层时保留浮层，离开两者后延迟 120ms 关闭。

键盘聚焦、Enter/Space 和触屏点击立即打开，不等待 500ms；Escape 关闭当前浮层。

## 4. 每日记录数据模型

采用“每日聚合 + 逐题明细”的混合模型。浏览器本地日期键使用 `YYYY-MM-DD`，不能直接截取 UTC ISO 日期。

### 4.1 逐题记录

扩展 `PracticeSession`：

```ts
interface PracticeSession {
  id: string
  localDate: string
  quizType?: QuizType
  isCorrect: boolean
  questionPrompt?: string
  responseMs: number
  startedAt: string
  endedAt: string
  // 兼容现有汇总字段
}
```

逐题记录用于详情弹窗，容量从 1000 条提高到 5000 条。加载旧数据时，根据 `endedAt` 转成本地日期，并从现有正确数和题干尽可能补齐；无法判断题型的旧记录只计入综合统计，不进入具体题型筛选，也不丢弃记录。

### 4.2 每日聚合

```ts
interface DailyPracticeRecord {
  date: string
  totalQuestions: number
  correctQuestions: number
  totalResponseMs: number
  byQuizType: Partial<Record<QuizType, DailyQuizTypeStats>>
}
```

每日聚合用于今日指标和热力图。提交一道题时，逐题记录与当天聚合在同一次状态更新中写入。保留最近 400 天，保证最近 365 天视图不会因边界时间丢失数据。

旧存储没有 `dailyRecords` 时，从现有 sessions 一次性重建。归一化后写回采用向后兼容默认值，损坏条目跳过而不是阻断页面加载。

## 5. 今日统计与详情弹窗

今日练习顶部三个指标改为可点击按钮：

- 已完成 N 题
- 正确率 N%
- 平均反应 N 秒

它们只汇总浏览器本地当天记录。跨到新日期时自然显示为零，历史数据仍保留。

点击任一指标打开统一 `PracticeDetailDialog`，默认日期为今天。弹窗包括：

1. 日期与综合题量、正确率、平均反应时间。
2. “全部、找音、认音、八度、音程、调内音”筛选按钮组。
3. 各题型的题量、正确数、正确率、平均反应时间。
4. 逐题明细：时间、题型、题干、结果和反应时间。
5. 空日期显示“当天还没有练习记录”。

弹窗支持遮罩点击、关闭按钮和 Escape 关闭，打开时使用 `role="dialog"` 与 `aria-modal="true"`。

## 6. 最近 365 天热力图

在今日练习配置区域下方增加 `PracticeHeatmap`，不新增 Tab。布局使用 53 列周网格和 7 行星期，展示从今天向前滚动的最近 365 天，并保留月标签、星期标签和题量图例。

固定题量等级：

| 等级 | 当日题量 |
|---|---|
| 0 | 0 |
| 1 | 1-4 |
| 2 | 5-9 |
| 3 | 10-19 |
| 4 | 20 及以上 |

日期方格是固定尺寸按钮。悬停显示轻量提示：日期、题量、正确率、平均反应时间；点击打开同一个详情弹窗并切换到对应日期。无记录日期也可点击，弹窗显示空状态。

移动端允许热力图区域横向滚动，方格尺寸不压缩，不能挤压页面整体宽度。

## 7. 模块边界

| 模块 | 职责 |
|---|---|
| `src/lib/guitarFretboard/practiceHistory.ts` | 本地日期、按日/题型汇总、365 天数据生成、热力等级 |
| `src/lib/guitarFretboard/storage.ts` | 新旧数据归一化、容量限制和持久化 |
| `src/components/guitar-fretboard/PracticeStats.tsx` | 今日可点击指标 |
| `src/components/guitar-fretboard/PracticeDetailDialog.tsx` | 日期和题型明细弹窗 |
| `src/components/guitar-fretboard/PracticeHeatmap.tsx` | 365 天周网格与日期提示 |
| `src/components/ui/GlossaryTerm.tsx` | 延迟悬停、圆环、浮层与循环保护 |
| `src/data/glossary.ts` | 结构化术语内容和文本分词 |

页面组件只组合上述模块并维护当前弹窗日期，不承担日期聚合算法。

## 8. 验收条件

1. 地图和设置试听选择在 1/3/5 秒到期后圆点与音名同时消失；持续模式不自动消失。
2. 今日练习在任何点击显示配置下都不会自动隐藏答案圆点或音名。
3. 地图七种音阶/和弦按钮中的专业术语均可打开解释。
4. 鼠标悬停不足 500ms 不打开浮层；圆环反映等待进度；键盘和点击可立即打开。
5. 相关词条没有固定嵌套层数，并且循环引用不会无限渲染。
6. 今日指标只统计本地当天，跨日归零；旧记录仍可在热力图查看。
7. 三个今日指标均能打开弹窗，并能按五类题型筛选。
8. 最近 365 天热力图按题量正确分级；悬停显示综合统计，点击打开该日详情。
9. 旧 localStorage 数据能兼容加载和迁移。
10. 业务单元测试、组件交互测试、页面测试、Lint 和生产构建通过。
