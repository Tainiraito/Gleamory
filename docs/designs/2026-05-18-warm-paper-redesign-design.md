# Gleamory 暖纸墨韵重设计 — Design Spec

> 状态：已实现，作为当前全站视觉语言的历史设计依据。

> 设计方向：暖纸墨韵（Warm Paper & Ink）
> 项目：Gleamory 微光集
> 日期：2026-05-18

> 2026-07-17 排版决策：字体部分已由《[全站三层字体体系设计](2026-07-17-typography-system-design.md)》取代；发生冲突时以新规范为准。本文件继续定义暖纸、琥珀、墨黑、细边框和编辑式留白，不再定义字体 family、字重和字阶。

## 1. 设计哲学

**「一页信纸，一道微光」**

每个项目卡片像一封展开的信，封面图是信中的照片，文字是手写的记录。
粉紫的光只在鼠标经过时悄悄渗出纸缝——呼应「微光集」的名字。

不是「漂亮模板」，而是一封封展开的、有点旧的、带着温度的信。

## 2. 5 大签名元素（Signature Elements）

### ① 微光渗漏 · Glimmer Leak ✨

卡片 hover 时，底部溢出柔和的粉紫光晕——像封缄的纸缝里渗出的一线光。

- CSS 实现：`::after` 伪元素 + `box-shadow` + `opacity` 过渡
- 常态：`opacity: 0`
- hover：`opacity: 1`，光晕从底部向上扩散 `translateY(0) → translateY(-4px)`
- 色值：`rgba(247, 131, 172, 0.08)` → `rgba(247, 131, 172, 0.15)`
- **Framer Motion：** 用 `whileHover` 控制，`transition: { duration: 0.4, ease: 'easeOut' }`

### ② 纸角折痕 · Paper Corner Fold 📐

卡片右上角有一个极淡的折痕效果——像纸角被轻轻翻起过。

- 仅用于 featured 卡片
- CSS 实现：`::before` 伪元素，`border-style: solid` 三角
- 颜色：背景色 `#f7f4ef`（与 page 背景同色，造成「透过折痕看到桌面」的错觉）
- 大小：24px × 24px 直角三角形
- corner：top-right
- hover 时折痕不变化（保持幽静感）

### ③ 旧纸纹理 · Aged Paper Grain 🏛️

页面背景有一层几乎不可见的颗粒感纹理。

- CSS 实现：`<svg>` filter + CSS `background-image`，用极小尺寸（如 200×200）的 `feTurbulence` 生成噪点
- 不透明度：`0.015` — 几乎不可见，但让纯色背景「不无聊」
- 所有浏览器兼容：用 base64 内联 SVG
- 只在页面背景生效，不在卡片背景上叠加（卡片纯白）

### ④ 活版句读 · Letterpress Ornaments ❦

章节标题之间用极细的古风排版装饰符号点缀。

- 符号库：`❦ ⸎ ※ ✦ ❧`（仅用这 5 个）
- 色值：`#0c0a12` 紫黑，`opacity: 0.15`
- 位置：大区块标题下方，替代传统的 `border-bottom`
- 大小：`font-size: 12px`，等宽间距
- 符号不承载功能含义，纯装饰

### ⑤ 押印标签 · Stamp Tags 🔲

项目的 tags 和 status 不再是普通圆角标签——而是墨印风格。

- 实现：`border: 1px solid rgba(44,42,48,0.12)` + 细体字 + 约 `-2deg` 随机倾斜
- 背景：透明（只在纸上印刷，没有填充色块）
- 字体：`font-sans`（本地 `Gleamory UI`），`font-size: 12px`，`letter-spacing: 0.05em`
- hover：不变化（保持「已经印好了」的感觉）
- 多个 tag 之间用 `·` （中间点）分隔，不换行

## 3. 首页项目目录（ProjectListItem + ProjectGrid）

### 分类导航（2026-07-16 补充）

- 顶部 featured 主项目保持独立展示。
- 普通项目按用户目标分为“弦歌有声、丹青拾光、浮生半日”，分类顺序和项目归属由独立展示配置维护，不改变 `projects.json` 主数据结构。
- 项目主栏以紧凑的左侧分类栏配合右侧单列项目目录，分类标题使用“卷一、卷二、卷三”、宋体标题和简短说明建立章节导航；窄屏恢复为标题在上、列表在下。
- 项目行不使用矩形背景、四周边框或重复序号，以水平分隔线、无边框标签、状态圆点和跳转箭头构成开放式目录；不再生成“敬请期待”占位项。
- 新项目暂未写入分类配置时进入“其他项目”回退分组，避免卡片静默消失；元数据测试仍要求正式项目在提交前完成归类。
- 项目行默认直接显示，不依赖进入视口动画，避免首次加载时短暂空白；悬停动效遵循系统 `prefers-reduced-motion` 设置。
- 分类栏不再显示项目数量，避免与列表内容重复。三组命名及出处为：
  - **弦歌有声**：取[《论语·阳货》](https://ctext.org/lunyu-zhushu/yang-huo/zh)“闻弦歌之声”，简介为“宫商迭奏，安放乐器、节拍与听辨练习”。
  - **丹青拾光**：借杜甫[《丹青引赠曹霸将军》](https://zh.wikisource.org/zh-hans/%E4%B8%B9%E9%9D%92%E5%BC%95%E8%B4%88%E6%9B%B9%E9%9C%B8%E5%B0%87%E8%BB%8D)“丹青不知老将至”，简介为“丹青不老，收录图像与内容的灵光”。
  - **浮生半日**：取李涉[《题鹤林寺僧舍》](https://zh.wikisource.org/zh-hans/%E9%A1%8C%E9%B6%B4%E6%9E%97%E5%AF%BA%E5%83%A7%E8%88%8D)“偷得浮生半日闲”，简介为“偷得片刻闲，容一场偶遇与欢喜”。

### 全局文本框选（2026-07-16 补充）

- 使用 `--selection-bg: #d9b28b` 与 `--selection-text: #1a1210`，形成清晰的暖琥珀底、深墨文字组合。
- `::selection` 同时清除文字阴影，确保正文、标题与输入框内的选中范围边界明确。
- 不复用透明度仅 `0.08` 的 `--accent-glow`；该变量继续用于轻量悬停与选项背景，不承担文本选中反馈。

### 今日一页：月历与诗笺（2026-07-16 补充）

- 移除原先两张白底圆角阴影卡片，月历与诗笺合并为一个只有上下边线的开放式横向区块。
- 1760px 以上采用“项目主栏 / 18rem 右侧栏”，主视觉位于分栏上方并跨满内容容器，月历、诗笺和“流光忆庭”依次进入右侧栏；该阈值避免普通笔记本宽度过早压缩项目目录。
- 1760px 以下，月历与诗笺在项目目录下方双列排列，窄屏上下排列，并用水平线分隔；时间线在其后占满可用宽度。
- 月历以“今日日历”、月份和年份建立编辑排版层级，日期采用等宽小字，今日使用实色琥珀方印标记。
- 诗词以“每日诗笺”作为小标题，正文使用 `font-display` 的 `Gleamory Editorial` 500；出处通过短琥珀横线连接，并保留远程接口、8 秒超时与本地诗库回退规则。
- 月历、诗笺和“流光忆庭”统一水平内边距、标题基线和整列分隔线，不再叠加不齐的局部卡片边框。
- “流光忆庭”改为适配侧栏的紧凑时间轴，默认 5 条直接可见；额外记录展开/收起时恢复高度与透明度过渡，并遵循减少动态效果设置。
- “流光忆庭”只展示项目上线、核心能力大改、重大版本和下线迁移等里程碑；小修小改与技术实现细节只进入 CHANGELOG 或开发记录。

### 首页主视觉轮播（2026-07-16 替代原 Featured 卡片）

- 主视觉不再是跳回首页自身的项目卡片，只从 `微光集` 数据项读取站点名与简介。
- 隐藏标签、状态、版本和更新时间，保持一处明确的标题焦点。
- 主视觉跨满统一的 90rem 内容容器，与下方右侧栏外沿对齐，不在右侧留下空列。
- 首页、普通功能页与对应顶部站点标识统一使用居中的 90rem 标准容器；指板训练和音高检测使用 100rem 宽屏容器。两档均由 `PageContainer` 提供，页面不再各自硬编码百分比边距。
- 使用浅暖纸信息区搭配标准 16:9 图片视窗，图片保持原有色彩与主体构图；不使用大面积纯黑标题底，也不把 16:9 壁纸强行裁成超宽横幅。
- 浅暖纸信息区使用一条无边框的编辑式翻页轨道：左侧为 `01 / 03` 页码，中间以细线延展，右侧提供上一张、暂停/继续和下一张；移除方框工具栏、图片覆盖控件和底部分段进度，避免操作重复与画面遮挡。
- 当前三张图片由 `src/data/homeHeroSlides.ts` 配置，新增图片时先转换为优化后的 WebP/JPEG，再追加配置项。
- 默认每 7 秒自动切换；悬停、焦点进入或用户暂停时停止，方向键可切换图片；减少动态效果时直接显示最终状态且不自动播放。
- 移动端信息与控制在上、图片在下；桌面端信息区与 16:9 图片并排等高，标题与控制保持可读且不遮挡主要人物。

## 4. 抽卡页（GachaSimulator）

### 整体布局

| 属性         | 值                                                              |
| :----------- | :-------------------------------------------------------------- |
| 背景         | 同首页 `#f7f4ef` + 旧纸纹理                                     |
| 页面最大宽度 | `max-w-3xl mx-auto` — 比首页稍窄，像一页手帐                    |
| 间距         | 区块之间 `gap-6 sm:gap-8`                                       |
| 区块卡片     | 每个独立功能块（条目管理/抽卡区/结果）各有独立的 0.5px 线框纸片 |

### ⭐ 签名元素：橡皮图章按钮 (Rubber Stamp Button)

抽卡主按钮是整页的视觉焦点，也是 gacha 最有个性的元素：

- 形状：**正方形**（80×80px），而非普通圆形/矩形按钮
- 背景：`#0c0a12` 紫黑（深墨色）
- 文字：`#f7f4ef`（纸色），`font-family: 'Source Han Serif CN'`，大字
- 内容：**「抽」** 单字，竖排居中，`font-size: 28px`，`font-weight: 700`
- 下方小字：`pull` 英文，`font-size: 9px`，`letter-spacing: 0.15em`
- 边框：`0.5px solid #0c0a12`
- 旋转：`-2deg` 微偏，像真的手盖印章
- 悬停：`rotate(0deg)` + `scale(1.05)` + 底部微光渗出
- 点击：`scale(0.95)` 像用力按印章
- shadow：无 box-shadow，只有 `0 1px 2px rgba(44,42,48,0.06)`

### ⭐ 签名元素：抽签纸片 (Paper Slip Draw)

抽出的结果不是表格——而是一张张独立的纸签：

- 每个抽到的条目是一张长方形「纸片」
- 背景：`#ffffff`，0.5px 线框
- 左边有一条 **锯齿撕痕**（CSS `border-image` / clip-path 模拟撕裂边缘）
- 纸片内：条目名称（大号 `font-display`）+ 底部右对齐小字 `第 N 抽`
- 纸片随机微转：`-1deg ~ 1deg`，相互略微错落
- 动画：从顶部滑入 + 轻轻落下，`spring: { stiffness: 300, damping: 25 }`
- 纸片宽度：`180px ~ 220px`（随机），两到三列排列
- 空状态（无结果时）：显示 `✦` +「开始抽卡吧」

### ⭐ 签名元素：抽卡动画

点击「抽」按钮后的流程：

1. 按钮向下弹动 `scale(0.95)` 再回弹
2. 结果区域出现 **纸片飘落** 动画：
   - 每张纸片从 `y: -40, opacity: 0` 开始
   - 按顺序 `delay: index * 0.08` 逐个出现
   - 落地后有微小弹跳 `spring`
3. 全部出现后，纸片轻微抖动 `x: [-1, 1, -1, 0]` 持续 0.3s

### 抽卡区布局

- 左侧：抽卡按钮（橡皮图章，居中）
- 右侧：抽取次数控制（`+` `-` 按钮，纯数字输入）
- 下方：当前模式显示（「唯一模式」/「重复模式」）

### 条目管理区

- Textarea：复古笔记本质感
  - 背景：极淡的横线 `repeating-linear-gradient`，像笔记本横线纸
  - 横线色值：`rgba(44,42,48,0.03)`，间隔 24px
  - 占位符文字：使用 `font-sans` 的本地 `Gleamory UI`
- 追加/覆盖切换：保留现有设计但微调——两按钮拼成 toggle，无背景色块，`0.5px` 线框包围
- 去重勾选框：`accent-color: #0c0a12`（紫黑），不再是粉色

### 结果展示

- **抽取历史**：用「纸签飘落」形式展示，不清除（但可以通过按钮清除）
- 历史条目排序：最新的在上
- 超出屏幕 → 内部滚动容器
- 清除历史按钮：小号文字按钮，`color: rgba(44,42,48,0.3)`，hover 时变深
