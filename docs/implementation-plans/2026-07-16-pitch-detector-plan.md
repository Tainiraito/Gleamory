## 相对初始实现的修订

- 初始 WIP 只包含页面和算法，没有应用路由、项目元数据或文档闭环；本轮补齐为可访问功能。
- 初始 `pitchTransfer.ts` 没有调用方；本轮从音轨分离结果卡提供“检测音高”入口。
- 初始阈值仅影响搜索提前结束；本轮让最终有效性判断使用同一阈值。
- 初始上传分析忽略短于默认帧长的片段；本轮使用实际片段长度完成一次检测。
- 初始页面以大标题、多个同权指标卡和卡片式侧栏分散注意力；本轮改为大音名、横向音分标尺和钢琴卷帘曲线构成的连续阅读路径。
- 第二轮将重复的工作区元信息和曲线标题收为无障碍标题与单行隐私提示，并让曲线按 `960 × 360` 坐标比例自适应宽度。
- v0.5.0 属于向后兼容的局部功能更新：不引入后端或第三方音频库，在现有视口与播放状态数据流内增加播放位置跟随，并修正工作台分界线对齐。

## 剩余验证

- Codex 内置浏览器仍无法接受 WSL 工作区的 `file:///home/...` URI；v0.4.0 曾通过本机 Edge 无头模式完成桌面与移动空闲态截图，v0.5.0 未取得外部浏览器降级授权，因此本轮没有新增渲染截图。
- v0.5.0 已通过页面交互测试验证跟随开关、播放游标平移和拖拽后自动退出；桌面边界线对齐与真实浏览器中的激活态仍需补充渲染验收。
- Tab 切换、上传入口、权限失败后的可恢复状态由页面 Vitest 覆盖。
- 麦克风与电脑音频仍需要用户在真实浏览器中授予权限；自动化验收未接受媒体权限弹窗。
- GitHub Pages 曾因自定义域名证书尚未签发且未强制 HTTPS，把仓库地址重定向到 HTTP；现 `gleamory.lovelysia.top` 证书已生效并启用 Enforce HTTPS，代码仍保留安全上下文与 API 缺失提示作为恢复边界。
